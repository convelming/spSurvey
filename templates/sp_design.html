4. SP问卷设计页面

支持灵活配置：先添加选项（Alternative），再给每个选项添加变量（Variable）。

每个变量可填写参数默认值（先验）和变量水平值（用英文逗号分隔）。

ASC处理规则：每个选项自动内置 ASC；默认第一个选项为基准项（ASC=0，不计入参数）；其余选项 ASC 计入参数。

基础设置

保存时必填；同名会覆盖更新。

支持 > / >= / < / <= 链式比较，以及变量与常数的 + / - / * / / 表达式，例如 `car.travel_time <= bus.in_vehicle_time * 1.6`。
